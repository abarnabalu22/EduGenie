# EduGenie – Demo Video Script (about 4-5 minutes)

**Setup:** Record screen + microphone (OBS Studio, or Win+G / Zoom). Have VS Code and the browser ready.

1. **Intro (20s)** – "Hello, I am <name>, from <college>. My Naan Mudhalvan project is EduGenie, a Google Gemini powered learning assistant."
2. **Problem (20s)** – "Students need simple explanations, practice and a study plan. EduGenie provides all of these using AI."
3. **Code walkthrough (60s)** – Show VS Code: `app.py` (Gemini client + helper function), `requirements.txt`, `.env` (blur the key!). Say how the prompt is built from topic, level and language.
4. **Run (20s)** – In terminal: `streamlit run app.py`. Browser opens, paste API key in sidebar.
5. **Live demo (120s)**
   - Explain Topic: "Photosynthesis", Beginner.
   - Change language to Tamil, explain again.
   - Quiz: "Python Basics", 5 questions, answer and submit, show score.
   - Study Plan: "Learn Python", 14 days, 2 hours.
   - Summarizer: paste a paragraph.
   - Ask Tutor: ask a follow-up doubt.
6. **GitHub (20s)** – Show the repository page with README.
7. **Conclusion (20s)** – "EduGenie makes learning personalised and accessible. Future work: PDF Q&A and voice. Thank you."

**After recording:** upload to Google Drive -> Share -> "Anyone with the link" -> Viewer -> copy link.
